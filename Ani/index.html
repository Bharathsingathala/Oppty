ANIMATION

CSS Animation is used to change the style of an element automatically over time without requiring user interaction like hover or click.

@keyframe

@keyframes is used to define the different stages of an animation.

Selector + @keyframe

selector {
animation-name: name;
animation-duration: time;
animation-iteration-count: number;
animation-timing-function: ease |
linear | etc; animation-delay: time;
animation-direction: normal |
reverse | alternate;
}

@keyframes animationName {
from {
property: value;
}
to {
property:value;
}
}

Example

Fade-in and slide-up Card:

Create a card that starts transparent and moving to certain pixels and animates to actual card on page load.

Color Pulse Button:

Create a 3 button with 3 different color and when mouse hover is happened, change the background color to button color with smooth transition.

Spinner on Button:

Create a button and when user hover on it the spinner or loader will appear on the button.

Card Flip:

Create a flipping Card (Front/back) using Key Frames.
