PSEUDO CLASS

A pseudo-class defines a special state of an element like hover, focus, active, first-child, etc.

PSEUDO ELEMENT

A pseudo-element styles a specific part of an element like ::before, ::after, ::first-letter, etc.

Selector + Pseudo
selector:pseudo-class{

    property:value;

}

selector::pseudo-element{

    property:value;

}

Examples

Hover Effect

Change background color when mouse hovers.


Focus Effect

Highlight input when it gets focus.


First Letter

Style the first letter of a paragraph.


Before & After

Insert content before and after an element.


Selection

Change the color of selected text.
